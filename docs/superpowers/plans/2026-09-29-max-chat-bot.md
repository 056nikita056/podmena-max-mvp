# MAX Chat Bot Implementation Plan

**Goal:** провести создание и согласование подмены в личных чатах существующего бота MAX.

**Architecture:** `server/chat-bot.js` ведёт диалоги и использует `createDomain`; `server/store.js` хранит профили и состояние; `server/http.js` проверяет webhook, вызывает бот и отправляет ответы через MAX API. В браузерный путь изменения не требуются.

**Tech Stack:** Node.js 24, libSQL/Turso, Vercel Functions, MAX Bot API.

## Global Constraints

- Бот-токен и webhook-secret читаются только из окружения.
- Для реального подтверждения нужен ответ отдельного MAX user ID кандидата.
- В чат-поиске не показывать модельные YouDo и Профи.ру.
- Webhook и исходящие сообщения используют `platform-api2.max.ru` и локально включённый публичный корневой сертификат.
